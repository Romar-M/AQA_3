# AQA_3

Третья практическая по Python: параметризованный декоратор `retry`.

`@retry(max_attempts=3, delay=1)` перехватывает `Exception` и повторяет вызов после паузы. `max_attempts` включает первый вызов. После последней неудачи исходное исключение передаётся вызывающему коду без дополнительной паузы.

`functools.wraps` сохраняет имя и docstring функции. Позиционные и именованные аргументы передаются через `*args` и `**kwargs`.

Требуется Python 3. Внешние библиотеки не нужны.

```bash
python main.py
```

Пример завершается успешно с третьей попытки, с двумя паузами по одной секунде:

```text
Attempt 1
Attempt 2
Attempt 3
Success
```
